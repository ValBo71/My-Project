# Ръководство за работа с Jobs Tracker (Observer v2)

Този документ предоставя кратко ръководство за инсталиране, конфигуриране и стартиране на приложението **Observer v2** (разположено в папка `08.Observer/02.ObserverV2`).

---

## 🚀 Какво представлява Observer v2?
**Observer v2** е уеб приложение, разработено с **Python (Flask)** и **SQLite**, което автоматично събира (scrape), обработва и визуализира обяви за работа от **dev.bg**, **LinkedIn** и **jobs.bg**.

### Ключови подобрения спрямо версия 1:
1. **Настройки на URL адресите от уеб интерфейса**: Добавен е нов таб **"Настройки"**, от който можете динамично да променяте линковете за търсене.
2. **Опционално сканиране**: Можете да оставите полето за даден сайт празно, за да бъде пропуснат по време на обновяването.
3. **Нулиране на базата данни**: Опция за пълно изчистване на събраните обяви и компании с един клик.
4. **Изолация на порта**: Работи на порт **5001**, за да не си пречи с предходната версия.
5. **Стартиране и на macOS**: `run_mac.command` инсталира всичко нужно и стартира приложението.

---

## 📁 Структура на проекта (08.Observer/02.ObserverV2)
*   `run.bat` — Скрипт за автоматично стартиране под Windows.
*   `run_mac.command` — Скрипт за автоматично стартиране под macOS.
*   `app.py` — Главен Flask сървър, API маршрути, контролери и логване (`app.log`).
*   `config.py` — Конфигурационни настройки (URL адреси по подразбиране, порт, debug режим, данни за LinkedIn).
*   `database.py` — SQLite база данни и операции по създаване и четене.
*   `scraper.py` — Скрапинг машини (Playwright & urllib requests).
*   `parser.py` — Обработка на съдържанието чрез BeautifulSoup и регулярни изрази.
*   `linkedin_credentials.json` — Локални данни за достъп до LinkedIn (по избор).
*   `linkedin_session.json` — Запазена сесия за LinkedIn (бисквитки).
*   `jobs.db` — SQLite база данни (създава се автоматично).

## 🛠️ Инструкции за стартиране

### А. Автоматично стартиране (Windows)
1. Отидете в папка `08.Observer/02.ObserverV2`.
2. Стартирайте **`run.bat`** с двоен клик.
3. Скриптът автоматично ще инсталира нужните Python пакети, ще изтегли Playwright Chromium браузър и ще отвори приложението в браузъра по подразбиране.

### Б. Автоматично стартиране (macOS)
1. Отидете в папка `08.Observer/02.ObserverV2` във Finder.
2. Стартирайте **`run_mac.command`** с двоен клик (или `./run_mac.command` в Terminal).
3. Ако няма работещ Python 3, скриптът сам изтегля преносима версия в `python_portable/` (без администраторски права). След това инсталира пакетите и Chromium и отваря приложението.
4. Ако macOS блокира файла при първо стартиране, разрешете го от **System Settings → Privacy & Security**.

### В. Ръчно стартиране (Всички операционни системи)
1. Инсталирайте нужните зависимости:
   ```bash
   pip install flask beautifulsoup4 lxml playwright
   playwright install chromium
   ```
2. (Опционално) Конфигурирайте LinkedIn акаунт за безпроблемно събиране на обяви. Създайте файл `linkedin_credentials.json` в папка `08.Observer/02.ObserverV2` със следното съдържание:
   ```json
   {
     "email": "your_email@example.com",
     "password": "your_password"
   }
   ```
   Без този файл LinkedIn работи само докато е валидна запазената сесия; след това обновяването показва грешка за LinkedIn.
3. Стартирайте Flask приложението:
   ```bash
   python app.py
   ```
   За debug режим (Werkzeug debugger и автоматично презареждане) задайте преди това `OBSERVER_DEBUG=1`.
4. Отворете браузър и въведете: **`http://127.0.0.1:5001`**

## ⚙️ Начин на работа с интерфейса
*   **Обновяване**: При отваряне страницата веднага показва запазените обяви и започва обновяване на фона. Бутонът **"Обнови обявите"** пуска ново обновяване; докато едно тече, второ не може да започне. Ако някой от сайтовете не отговори, се показва предупреждение „Частично обновяване“ с името на източника.
*   **Основно табло (Главна страница)**: Визуализира събраните обяви с възможност за търсене в реално време по фирма, позиция или тех. стек. Можете да слагате цветни флагове на обявите (зелен, жълт, червен) за лесно филтриране. Флагът на обявата има предимство пред флага на фирмата.
*   **Таб "Фирми"**: Позволява управление на фирмите, задаване на дисплейни имена, добавяне на етикети и създаване на връзки (псевдоними/aliases) за обединяване на дублиращи се имена на фирми.
*   **Таб "Настройки"**: Мястото за конфигурация на линковете за сканиране и пълно изчистване на данните.
