# Дневник за Поддръжка на Автомобили (Car Maintenance Log - MVP)

Уеб-базирано приложение за проследяване на ремонти, смени на консумативи, документи и бъдещи обслужвания на автомобили. Проектът е подходящ за всякакви марки и модели (по подразбиране е конфигуриран с тестови данни за **Citroën C8 2.2 HDi** и **Saab 9-5 Aero**).

---

## 🚀 Функционалности на първата версия (MVP)

1. **Управление на Автомобили**:
   * Добавяне и редактиране на профили на коли (Марка, Модел, Двигател, Година, VIN, Регистрационен номер, Гориво, Пробег).
   * Възможност за прикачване на реални снимки за всеки автомобил.
   * Бързо превключване на активния автомобил чрез Cookie сесия.
2. **Сервизен Дневник**:
   * Пълен списък на извършените ремонти, обслужвания и смени.
   * Филтриране по категории, тип дейност и търсене по ключова дума.
   * Прикачване на документи (фактури, разпечатки, касови бележки в PDF/изображения) към всяко обслужване.
   * Изчисляване на общите разходи, разходи за части и труд поотделно в **Евро (€)**.
3. **Автоматични Напомняния (Интелигентна Поддръжка)**:
   * Правила за следваща смяна по пробег (км), време (месеци) или комбинация от двете.
   * **Алгоритъм за приоритет**: изчислява следващото обслужване по това събитие, което настъпи първо.
   * **Цветови статуси на спешност**:
     * 🔴 **Червен**: Просрочено обслужване.
     * 🟡 **Жълт**: Наближаващ срок или пробег (в рамките на предварително зададени граници).
     * 🟢 **Зелен**: Всичко е изрядно и в срок.
     * ⚪ **Сив**: Няма въведени достатъчно данни за пресмятане.
4. **Интуитивно Табло (Dashboard)**:
   * Бърз поглед над активния автомобил, изминатия пробег и разходите за текущата година.
   * Панел за бързи действия (Ново обслужване, Ново напомняне).
   * Списък с критични предупреждения за просрочени или наближаващи ремонти.

## 🛠 Технологичен стек

* **Слоеве на кода**: Чиста 3-слойна архитектура (Core, Infrastructure, Web)
* **Backend**: ASP.NET Core 9.0 (Razor Pages)
* **ORM**: Entity Framework Core 9.0
* **База данни**: MS SQL Server (по подразбиране LocalDB за по-лесно локално пускане)
* **UI**: Bootstrap 5 + FontAwesome за модерни плоски икони
* **Стил**: Изчистен, премиум светъл дизайн с 90-градусови прави ъгли (без закръгляне) съгласно UI гайдлайните.

## 💻 Локално стартиране на проекта

### Системни изисквания:
* [.NET 9.0 SDK](https://dotnet.microsoft.com/download)
* SQL Server LocalDB (идва инсталиран с Visual Studio) или друга SQL Server база данни.

### Стъпки за стартиране:

1. **Отидете в директорията на проекта**:
   ```bash
   cd "CarMaintenance.Web"
   ```
2. **Стартирайте приложението**:
   ```bash
   dotnet run
   ```
3. **Отворете браузър на посочения в конзолата адрес**:
   * Обикновено това е `http://localhost:5248`.

*Забележка: Базата данни ще бъде създадена автоматично на вашия LocalDB сървър и автоматично заредена с първоначални примерни данни на двата автомобила при първото стартиране на проекта.*

## 📂 Структура на софтуера

* **CarMaintenance.Core**: Съдържа бизнес обектите (`Car`, `ServiceRecord`, `ServiceItem`, `MaintenanceRule`, `MileageHistory`, `Document`) и енумерациите.
* **CarMaintenance.Infrastructure**:
  * `ApplicationDbContext` - Връзка с базата чрез EF Core Fluent API.
  * `DbInitializer` - Логика за засяване на тестовите данни.
  * `MaintenanceCalculator` - Математическият алгоритъм за статусите.
* **CarMaintenance.Web**: Презентационният слой (Razor страници, CSS, статични файлове, логика на контролерите).
