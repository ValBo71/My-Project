# dev.bg Automation QA Jobs Tracker

Това е уеб приложение, разработено на **Python (Flask)** и **SQLite**, което автоматично извлича (scrape-ва), обработва и визуализира обяви за работа за **Automation QA** роли от следния линк в **dev.bg**:
`https://dev.bg/company/jobs/automation-qa/?_job_location=sofiya%2Cremote&_seniority=mid-level%2Csenior`

## Основни функционалности
1. **Автоматично обновяване при зареждане:** При отваряне на приложението то автоматично прочита целевата страница на dev.bg, проверява за нови обяви и ги записва.
2. **Паралелно извличане (Concurrency):** Детайлите на новите обяви се извличат едновременно в отделни нишки (`ThreadPoolExecutor`), което ускорява зареждането до под 2 секунди.
3. **Защита срещу дублиране:** Обявите се записват в SQLite база данни, като техният уникален URL адрес се използва като първичен ключ (`PRIMARY KEY`) за предотвратяване на дублирани записи.
4. **Умно парсване:** Извличат се заглавие, компания, дата, изисквания (технологичен стек) и се сканира описанието на обявата за споменати **платени дни отпуск** и **диапазони на заплата** (в BGN, EUR или лв.).
5. **Интерактивен интерфейс:**
   * Сортирана таблица с всички обяви.
   * Търсене в реално време (по фирма, заглавие, технологии).
   * Филтриране по локация (Remote / Hybrid / Sofia), заплата и отпуск.
   * Детайлен изглед в модален прозорец на пълното описание на обявата.
   * Възможност за ръчно опресняване чрез AJAX бутон със спинер без презареждане на цялата страница.

## Структура на проекта
```text
Observer/
│
├── run.bat             # Стартов файл за Windows (автоматично инсталира библиотеки и пуска приложението)
├── app.py              # Главен Flask сървър, маршрути и логика за управление
├── config.py           # Конфигурация (URL адреси, БД пътища, настройки на scraper-а)
├── database.py         # Слой за база данни (SQLite инициализация и CRUD функции)
├── scraper.py          # Скрапер на страници (поддържа паралелно теглене на нишки)
├── parser.py           # Парсване на HTML чрез BeautifulSoup и Regex за отпуск/заплати
├── jobs.db             # База данни на SQLite (създава се автоматично при първо стартиране)
├── app.log             # Файл за логове от скрапване и грешки (създава се автоматично)
│
├── static/
│   └── css/
│       └── styles.css  # Модерна тъмна тема с анимации и стъклени ефекти (Glassmorphism)
│
└── templates/
    └── index.html      # Главен HTML шаблон на таблото за управление (Dashboard)
```

## Инструкции за стартиране

### Най-лесният начин (за Windows)
Просто щракнете два пъти върху файла **`run.bat`** в папката на проекта. Скриптът автоматично ще инсталира необходимите библиотеки (ако липсват), ще стартира уеб сървъра и ще отвори приложението във вашия браузър.

### Ръчен начин (всички операционни системи)

1. **Инсталиране на зависимостите:**
   Отворете терминал в директорията на проекта и изпълнете:
   ```bash
   pip install flask beautifulsoup4 lxml
   ```

2. **Стартиране на уеб сървъра:**
   Изпълнете следния скрипт:
   ```bash
   python app.py
   ```

3. **Достъп през браузър:**
   Отворете вашия браузър и отидете на:
   `http://127.0.0.1:5000`

## Логване и Грешки
* Ако dev.bg е недостъпен, приложението ще покаже съобщение за грешка на екрана, но **ще зареди успешно всички досегашни обяви от базата данни**.
* Всички събития и грешки се записват във файл `app.log` в папката на проекта за по-лесно дебъгване.
