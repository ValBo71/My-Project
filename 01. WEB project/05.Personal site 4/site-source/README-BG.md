# ValBo Apps — продуктов каталог

Сайтът представя приложенията и дава отделни връзки към Windows и macOS инсталаторите.

## Добавяне на нов продукт

1. Създайте отделна папка за продукта в `public/install` и поставете двата инсталатора вътре.
2. Добавете продуктова снимка в `public/images`.
3. Добавете един или повече кадри в полето `screenshots` на продукта. За всеки кадър задайте заглавие и кратко пояснение.
4. Добавете един запис в масива `products` във файла `data/products.ts`, включително `details` и трите факта за инсталацията: `runs`, `installNote` и `afterInstall`.
5. По избор: английски превод – запис в `english` в `data/i18n.ts` (без него продуктът показва българския текст и на EN). Ръководство – PDF файловете `public/manuals/<slug>-bg.pdf` и `<slug>-en.pdf` и slug-ът в списъка `manuals` в `data/i18n.ts` (без него продуктът няма линк към ръководство).
6. Стартирайте `npm run dev` за преглед и `npm run build` за проверка.

Всички категории, броят на продуктите, търсенето, продуктовите карти и галериите се обновяват автоматично от този масив.

## Публикуване в папката на сайта

Работете в отделно копие на `site-source` (извън папката на сайта, за да не попадне `node_modules` в нея):

```powershell
npm ci
npm run build
powershell -File scripts/copy_to_target.ps1
```

`copy_to_target.ps1` заменя готовия сайт в `05.Personal site 4` с новия build (старите файлове в `_next` се изтриват, `install` не се пипа) и обновява `site-source` там с изходния код. Всеки build дава нови имена (хешове) на JS файловете, затова браузърите не остават със стари кеширани версии – не редактирайте файловете в `_next` на ръка.

## Локално стартиране

```powershell
npm install
npm run dev
```

След това отворете `http://localhost:3000`.

В доставеното репо готовият сайт е в основната папка, а редакируемият код е в `site-source`. Преди локална разработка копирайте съдържанието на `../install` в `site-source/public/install`. Това копие не е включено втори път, за да не заема още около 169 MB.
