Observer V2 — автоматични онлайн инсталатори

Windows 10/11 x64: отворете ObserverV2-Windows-Setup.exe. Инсталира Python 3.12, библиотеките и Chromium и създава икони на Desktop и Start Menu. Не е нужен предварително инсталиран Python. Без администраторски права.

macOS (Intel и Apple Silicon): разархивирайте ObserverV2-macOS-Install.zip и отворете Install Observer V2.command. Създава приложението в ~/Applications/Observer V2.app. Това е автоматичен инсталационен скрипт, не подписан PKG/DMG. Подготвен е на Windows; изпълнението му на Mac не е проверено.

Нужен е интернет при първата инсталация и при извличане на обяви. Пакетите са неподписани; Windows/macOS може да поиска допълнително потвърждение. Затова абсолютно един клик на всеки компютър не е гарантиран. macOS може да изисква разрешение в Privacy & Security. Не изключвайте защитата на системата.

След инсталация стартирайте Observer V2 от иконата. Интерфейсът се отваря в браузъра. Затворете терминалния прозорец, за да спрете сървъра. Всеки старт използва свободен порт само на 127.0.0.1. Страницата показва веднага запазените обяви, а новите се извличат на фона; ако някой сайт не отговори, се показва предупреждение „Частично обновяване“.

Личните пароли, cookies, съществуващата база и логовете на автора не са включени. LinkedIn може да изисква собствена сесия; инсталаторът не гарантира достъп до сайтове с ограничения. Съществуващите настройки на търсенията са запазени от изходния код.

Потребителски данни:
Windows: %LOCALAPPDATA%\ObserverV2\data
macOS: ~/Library/Application Support/ObserverV2/data
Повторната инсталация запазва тази папка. Затворете приложението преди преинсталиране.

Деинсталиране: затворете приложението и изтрийте иконите/Observer V2.app и папката ObserverV2 от посоченото системно място. Запазете подпапката data, ако искате да съхраните обявите.

Версия от 26.09.2026: включва поправките от code review — екраниране на данните от сайтовете (XSS), защита на изчистването на базата от заявки от други сайтове, фоново обновяване без паралелни цикли, коректно отчитане на неуспешни източници, проверени SSL сертификати, поправени дати и разпознаване на технологии.

Проверено на Windows (26.09.2026): приложението от инсталатора е стартирано в изолирана Python среда с фиксираните зависимости и waitress — чиста база, HTTP отговор на интерфейса и CSS, визуализиране в Chromium, фоново обновяване, отказ на заявка от чужд сайт, запис на app.log в папката с данни. При проверката извличането от външни сайтове е заменено с тестов резултат. EXE е компилиран и вграденият setup.ps1 съвпада байт по байт с проверения; пълният процес на инсталатора (uv, икони) не е изпълняван. Проверен е PowerShell/Bash синтаксисът.

Технически: uv 0.8.22 с проверка SHA256 на инструмента; фиксирани преки Python зависимости. Транзитивните зависимости и Python patch версията се разрешават при инсталация. uv използва самостоятелни Python дистрибуции: https://docs.astral.sh/uv/guides/install-python/
